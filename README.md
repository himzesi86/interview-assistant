# 面试助手

Windows 11 电脑采集，安卓手机查看和操作。截图答题与语音回答是两个互不相关的页面，可以同时使用。

仓库和本地文件夹都是 `interview-assistant`。两端软件显示名都是「面试助手」。

## 分工

电脑负责截图、识别、画框、收音、转写、检索材料、调用模型和保存完整记录。手机负责查看、点选、修改文字、删除、停止生成和采用半截回答。

手机不是只读屏幕。它不保存完整提示词，也不另写日志。

## 连接

只支持同一 Wi-Fi，不使用 USB 或互联网。电脑在固定端口 `57321` 提供本地 HTTP 服务，并用配对口令限制访问。局域网内容明文传输。

二维码包含地址和口令，下方同时显示文字，扫不了时可以在手机上手输。口令一直有效。电脑重启后，地址没变就直接重连；地址变了就重新扫描。重置配对会立即断开当前手机，并使旧口令失效，下一台扫码的手机才能连接。只认一台手机。

默认使用正在上网的 Wi-Fi IPv4，不使用 IPv6。有多个地址时手动选择，不自动选择虚拟网卡。端口被占用时启动失败，不自动更换端口。防火墙拦截时提示手动允许专用网络访问，不请求管理员权限。

手机切到其他应用或锁屏后保持连接，因此保留一条只写「已连接」的前台常驻通知，不含题目、转写和回答。拒绝通知权限时仍可使用，但后台连接不保证。断开后手机只能查看已收到的内容，不能修改、生成、删除、开新场或采用半截。电脑继续采集，并完成已经开始的生成。重连后补齐内容。

## 模型与隐私

截图识别和语音转写使用 Windows 自带能力，画面和原始声音不离开电脑。语义分题、材料判断和回答共用同一套 OpenAI 兼容接口。地址、模型和密钥只在电脑上配置，密钥保存在 Windows 凭据管理器。

发给云端的是文字。设置修改从下一次请求生效，不中断正在进行的请求。没有配置就点生成时，不发请求，显示：

```text
【生成失败】CONFIG 尚未配置接口
```

缺少材料文件夹或 `个人材料.md` 时仍可生成，只在电脑上提示，不因此编造个人经历。

## 窗口与屏幕

设置中选择一块面试屏幕，并按其设备标识记住。快捷键和手机都只截这一块，不跟随鼠标。首次截图后，这一场锁定该屏幕。显示器断开就截图失败，不自动换屏；同一块重新接上后，当前场可以继续截。

完整窗口、历史和二维码都放在其余屏幕。只有一块屏幕时，电脑只留悬浮条。悬浮条只显示已连接、正在收音、最近一次截图成功或失败，不显示题目、转写、回答、二维码或口令。设置从托盘打开，窗口关闭只退到托盘，只有托盘中的「退出」才真正退出。

截图前隐藏本软件的窗口和悬浮条。连续截图全部完成后统一恢复；即使截图失败也立即恢复。所有屏幕，包括虚拟屏，都列在设置中。软件打开期间阻止电脑睡眠，但不阻止屏幕关闭。

## 场次

两个页面各自成场。公司、岗位和岗位描述可以留空；首次按下截图或开始收音后立即锁定，即使这次采集失败。之后不能修改，只能开新场。

场次名在首次采集时按电脑本地时间确定，格式为：

```text
2604022115-公司-岗位
```

公司和岗位各最多 40 个字，岗位描述最多 1000 个字，超出不能输入。空着的项省略，岗位描述不进入场次名。同一分钟冲突时追加 `-2`、`-3`。

开新场只影响当前页，并停止该页正在进行的生成。已写出的文字保留，失败行写成：

```text
【生成失败】STOP 已开新场
```

已排队的截图先全部完成并归入旧场，然后才进入历史。完全没有内容时不生成历史。语音开新场时先停止收音，把半句定稿，新场不自动收音。

## 截图题

截图按原始分辨率保存为 PNG。识别期间手机先显示整图和「正在分题」，没有题号，也不能作答。

贴着屏幕边缘、文字被截断的区域直接丢弃。完整内容先按整行重叠拼接：重叠行去掉空格后至少 4 个字符，并且逐字相同，重叠行只保留一次。拼接只在新图到达时判断一次，可跨多张；向前跳过失败记录、识别失败和没有完整题的图。合成后的题目归入最后一张，只占一个题号，框只覆盖最后一张里看得见的部分，完整文字显示在下方，所有局部图都保存。

阅读顺序默认从上到下、从左到右。中间空白至少能放下 8 个字，且纵向超过文字区域一半时，先读完左栏再读右栏。语义分题只能沿这个顺序分组，不能改字、漏行、重行或调换顺序。含义接不上才分成新题，同一题的选项、代码和续行留在一起。

分题超过 20 秒、接口失败或结果不合法时，按空行分题，并显示：

```text
自动分题失败，已按空行分开
```

这种结果仍可作答。没有完整题时保留整图并显示「没有完整题目」。识别本身失败时保留整图并显示「识别失败」。二者都不占题号，拼接时跳过。屏幕截图本身失败时，只发送可单独删除的「截图失败」记录。

每张图内按最终阅读顺序从 1 编号。只能删除整个框或整张图，不能合并、拆分或拖动。删除后当前图剩余题目从 1 重新编号。删除正在生成的题目会立即停止，不留半截和失败行。删除前面的图片不重算已经拼好的长题；删掉最后一张时，长题及其回答一起删除。

手机显示带编号框的整图，可双指缩放。点框或题目文字是同一操作。回答显示在对应题目下方。

### 材料判断

第一次点选先发送一次短判断，只包含题目文字。只有明确询问本人经历、项目、能力或求职动机时才使用材料。算法、代码、概念和普通做题不使用；只有同时问到「你做过吗」才使用。判断模板的回复不是明确的「需要」时，一律视为不需要。

判断不超过 10 秒。失败时不中断回答，按未使用材料继续，并显示「未能判断，未使用材料」。判断期间只显示「正在判断」；再次点击只停止判断，不写失败行，下一次仍先判断。

判断为需要后，材料块包含：

- `个人材料.md` 全文。
- 最多 3 份命中的项目 README 全文。
- 再按路径补充最多 2 个只含名字的项目。

判断为不需要时，整块材料不发送。

再次点击「未使用材料」或「未能判断」的普通回答时，跳过判断，直接结合材料重写。已经结合材料的完整回答再点击，就是微调：把上一版正文和代码放入请求，只改说法和语序，不更换经历、补充事实或改解法。可以连续微调最新一版。微调前清掉旧回答，失败后不恢复。

状态行只能从「已结合材料」点回「未使用材料」，并立即按不带材料、不带上一版的方式重写。不能从状态行打开材料。

截图回答去掉首尾空白后如果完全等于「这不是面试题，不需要作答」，再次点击不发请求，并提示「这不是面试题，不会重新生成」。多一个字就不锁定。

修改题目文字会立即清除回答、代码、失败行和材料决定，但不自动生成；下一次点选重新判断。只修改回答正文不清空，也不请求模型。

### 回答形式

非技术题在未使用材料时采用「结论、理由、收束」，不讲个人经历。使用材料后采用「结论、一段材料里的经历、收束」。

技术题或编程题先用几句口语讲思路，再给完整代码片段，不必硬讲个人经历。口述仍按中文 450 字或英文 250 词要求，但超出后完整保留。代码单独成块，不限长度，不计入口述，不运行、不编译，也不保证能通过。题目没有要求代码时不硬凑代码。注释与回答语言一致；中外文混合时，正文和注释都用中文。

每题有独立开关：

- 模型判断：要求写出、补全或实现代码时才给代码。
- 只要口述：删除模型返回的代码，不算失败。
- 思路加代码：没有代码时保留文字，并标记 `FORMAT 没有给出代码`。

新题默认由模型判断。切换开关会清除旧回答并立即重新生成，沿用已有材料决定，不重新判断。正在生成时不能切换。

## 语音回答

一场开始前选择识别语言，默认中文，可改成英文，开始后锁定。使用系统默认麦克风，软件不另选设备。快捷键或手机都可以开始和停止。

识别过程中按句末切段。中文「。」「！」「？」始终切段；英文 `.`、`!`、`?` 只有后面是空格或到达末尾才切段，因此不切开 `3.14`。这一版不识别 `Mr.` 之类缩写。没有句末标点时保持半句，实时显示在最后一行，但不能点选或编辑。停止时把半句定稿。定稿后不能拆分或合并，只能修改文字。

第一次点选的定稿成为起点。之后只能点这一句或更后面的句子；更早的句子只能查看。前文是起点之后、当前句之前的全部定稿，不含半句。超过 8000 字时，只保留靠近当前句且完整放下的句子，并在电脑上提示已截短。再次点击同一句时仍用这次的前文。

语音始终把当前句、前文、个人材料、项目资料、公司、岗位、岗位描述和可打开文件放入请求。没有输出方式开关，也不先判断材料。再点一次只换一种说法，不把上一版发给模型，也不因为「这不是面试题」这句话而锁定。

回答采用「结论、一段经历、收束」，两分钟口语，中文 450 字或英文 250 词；模型超出时完整保留，不截断、不算失败。经历以材料为准，只允许很近的说法。例如做过网页开发，可以说接触过软件开发，不能说成会软件开发或精通。不能新增材料中没有的公司、项目、职级、年限、数字或技术栈。

只有明确要求展示、打开、演示，或者回答讲到命中项目时，才加入括号动作。讲到几个项目就各加一个，按出现顺序单独成行。没有点名但明确要求展示时，把本次检索到的第一个项目放在所有动作前面。括号不用念，不计入字数，文件必须是材料文件夹内真实存在的相对路径。优先使用 README 点名且确实存在的文件，否则使用该 README。绝对路径、网址、快捷方式和外部路径都不用。模型编造的路径只删除对应动作。电脑不自动打开文件。

## 材料检索

用户选择一个文件夹并长期记住。根目录的 `个人材料.md` 可全文发送。任意一层含有 `README.md` 的文件夹都算项目，重名时使用相对路径。检索跳过 `.git`、`node_modules`、`dist`，不跟随快捷方式。

项目名去掉空格、不区分大小写；至少两个字，并按连续包含匹配。README 按同样的句末规则切句，原句去掉空格后出现在问题中才算命中，代码块不参与。超过 3 个时，先按问题中出现的项目名顺序选取，再用命中原句补满。只命中一个时，再按路径补充最多两个名字。一个都没命中时，不额外挑选项目。

语音检索范围是当前句加这次实际发送的前文。截图只有判断为需要材料时才检索，范围是最终题目文字。单个材料文件超过 8000 字时不截断，只在电脑上提示。非 UTF-8 文件跳过并提示，不猜测编码。

## 生成、错误与保存

回答边生成边显示在对应条目下方，不使用公共回答区。并行数量不限。再次点击正在生成的同一条，只停止这一条；点击另一条则并行生成。

手动停止、接口失败、超时、开新场和软件关闭都保留已生成文字，并另起一行写失败信息。一个字都没有时只留这一行。失败行不能编辑。20 秒没有首字或连续 20 秒没有新内容，记为超时。

错误码和说明固定为：

| 情况 | 显示 |
| --- | --- |
| 手动停止 | `【生成失败】STOP 已手动停止` |
| 开新场 | `【生成失败】STOP 已开新场` |
| 超时 | `【生成失败】TIMEOUT 接口超时` |
| 401、403 | `【生成失败】401/403 密钥或权限无效` |
| 404 | `【生成失败】404 接口地址无效` |
| 429 | `【生成失败】429 请求过于频繁` |
| 500 及以上 | `【生成失败】状态码 接口内部错误` |
| 其他 HTTP 状态 | `【生成失败】状态码 请求被拒绝` |
| 无法连接 | `【生成失败】NETWORK 无法连接接口` |
| 软件关闭或意外退出 | `【生成失败】CLOSED 软件已关闭` |
| 缺少配置 | `【生成失败】CONFIG 尚未配置接口` |
| 强制代码却没有代码 | `【生成失败】FORMAT 没有给出代码` |
| 其他 | `【生成失败】UNKNOWN 生成失败` |

说明只用这句中文，不保存接口原文和密钥。

手机断开不影响电脑继续完成生成。保存失败时显示「保存失败」，不把尚未成功的一端显示成已保存。

生成已经停止、半截至少有一个字且仍在当前场时，手机可以点「采用这段」。采用后去掉失败行，不再请求模型。重开后的 `CLOSED` 半截也可以采用。只有失败行、正在生成或已进入历史时不能采用。

旧回答再次生成时立即清除，不恢复。删除优先于另一端后到的修改。

## 提示词模板

电脑设置中有四份模板：分题、材料判断、截图回答、语音回答。它们可以整段修改，也可以删除材料和题目占位符。发送出去的正文就是模板最终文字，软件不额外追加内容。

占位符：

- 分题：`{{ 文字行 }}`。
- 判断：`{{ 题目 }}`。
- 截图回答：`{{ 题目 }}`、`{{ 输出方式 }}`、`{{ 材料块 }}`、`{{ 上一版回答 }}`。
- 语音回答：`{{ 当前句 }}`、`{{ 前文 }}`、`{{ 个人材料 }}`、`{{ 项目资料 }}`、`{{ 公司 }}`、`{{ 岗位 }}`、`{{ 岗位描述 }}`、`{{ 可打开文件 }}`。

没有内容的语音占位符替换成「（无）」。截图在不需要材料时，`{{ 材料块 }}` 整块不发送。不是微调时，`{{ 上一版回答 }}` 替换成「（无）」。删除哪个占位符，请求中就不再包含哪一项。

代码开关的后处理始终生效，即使删除了 `{{ 输出方式 }}`。语义分题即使修改模板，也仍校验分组结果。每份模板可以单独恢复默认，恢复只影响以后的请求。手机不能查看或修改模板。

完整提示词只保存在电脑上。多屏时从非面试屏的历史打开；单屏默认不打开，从托盘选择「仍要查看」后才显示。

## 操作

默认快捷键是截图 `Ctrl+Shift+S`、语音 `Ctrl+Shift+A`，都可以修改，后台也生效。新快捷键注册失败时保留旧快捷键并提示。手机也可以触发同样的截图和收音。

列表按时间正序排列，旧内容在上，半句始终在最下面。停在底部时自动跟随；向上翻阅时不打断，只显示「有新内容」。

电脑和手机都可以修改当前场文字，后保存的为准；正在生成的那一条两端都不能改。回答正文只能在手机上修改，电脑现场界面不显示回答。

删除整场和重置配对需要确认。开新场、删框、删图和停止生成不确认。每个页面只保留刚刚一步可撤销操作，电脑和手机共用这一步。退出或再做下一步后不能撤销。可撤销的是删框、删图、删除失败记录、改文字、改回答、采用半截和删除整场。生成、停止、开新场、重置、导出、截图和收音不能撤销。

麦克风打不开时每 3 秒重试，最长一分钟，期间显示「正在恢复收音」。重试中手动停止或开新场，也留下可单独删除的「收音失败」。时间耗尽同样留下该记录。正常收音中停止，只定稿半句，不增加失败记录。

## 历史、恢复与导出

历史按功能分开，开始时间倒序，当前场不进入历史。旧场只读，可以查看文字、图片、回答、材料状态、公司、岗位和岗位描述，也可以复制回答，但不能修改、生成或采用半截。电脑和手机都可以删除整场，另一端同步删除。

电脑是完整记录源头，保存在系统应用数据目录，不放进材料文件夹。内容包括题目、转写、回答、代码、动作、失败信息、项目名和实际提示词，因此包含当次材料正文。不保存密钥和原始语音。手机数据放在应用私有目录，不保存完整提示词。

关闭窗口不退出。真正退出或意外退出后，下次恢复两个当前场。正在生成的内容保留并标记 `CLOSED`。退出时正在收音，则自动恢复收音和原来的语言，但退出前未定稿的半句丢弃。恢复时麦克风失败，也按每 3 秒、最长一分钟重试。

电脑可以导出当前场或历史中的一场 ZIP。正在生成时不能导出；正在收音、识别或排队时可以导出，但只包含已经保存和已经分题完成的内容。包内是一份 Markdown、整图和裁剪图，包含最终文字、回答、代码、动作、失败行、材料状态、公司、岗位、岗位描述和识别语言。不含密钥、材料原文、完整提示词和未定稿半句。文件名使用场次名，冒号改成短横线，去掉 Windows 不允许的字符，重名追加序号。手机不能导出。删除软件中的场次不删除已导出的压缩包。

## 两端界面

手机跟随系统深浅色，字号默认中，可在小、中、大之间切换，只影响显示。允许横竖屏，以支持平板。最短边达到 600dp 视为平板；只有平板横屏的截图页分成左侧整图、右侧题目和回答，其他情况都是一列。手机前台保持常亮，离开后恢复系统设置。

长按复制当前保存的回答正文、代码和动作，不复制题目、失败行和图片。历史中也可以复制。

电脑首次打开直接进入设置，不使用强制向导。单屏时，公司、岗位、岗位描述和识别语言在首次采集前由手机填写或选择，之后锁定。

Windows 软件不随系统启动。安卓软件用 APK 直接安装，支持 Android 8 及以上，不上架应用商店。电脑日志记录连接、错误和全部面试内容，但不记录密钥与原始语音；手机不另写日志。

默认回答直接用「我」陈述，不出现「作为人工智能」「参考答案」或「以下是」。同一内容再次生成时允许换说法，但遵守当前模板、材料边界和输出开关。
